# Interface images

`measurements.png` and `sensors.png` are earlier interface captures, retained to preserve their previous temperature and humidity presentation. In `measurements.png`, only the upper-left wordmark was updated to the current **MycoBox.** branding. The existing icon and every pixel outside that small text region are unchanged, including all readings, curves, axes and activity tracks. The legacy `sensors.png` has no MycoBox wordmark and remains unchanged.

The other images are rendered from the project's current page renderer and local UI assets in Firefox. Host adapters supply example measurements, schedules, device assignments and firmware information.

These illustrations do not establish hardware performance. The mobile example uses a 487 CSS-pixel viewport.

For the meaning of the controls and states, see the [interface guide](../../docs/web-interface.md).
